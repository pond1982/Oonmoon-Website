ฉบับร่างสำหรับเจ้าของตรวจทาน

ตัวอย่างเว็บไซต์ในเครื่องนี้ยังไม่ใช่นโยบายความเป็นส่วนตัวฉบับสมบูรณ์ที่ได้รับอนุมัติ เจ้าของต้องยืนยันผู้ดำเนินการตามกฎหมาย วันที่มีผลใช้บังคับ ประเทศที่ให้บริการ ขั้นตอนดำเนินการตามคำขอด้านความเป็นส่วนตัว การจัดการข้อมูลที่ส่งถึงฝ่ายช่วยเหลือ และรายละเอียดการโฮสต์เว็บไซต์ ข้อความภาษาไทยและภาษาอังกฤษต้องได้รับอนุมัติก่อนเผยแพร่

ประกาศความเป็นส่วนตัว — ฉบับร่างสำหรับเจ้าของตรวจทาน

ฉบับร่างนี้อธิบายแอปอุ่นมูนรุ่น 0.7.8 ที่ตรวจสอบแล้ว และเว็บไซต์แบบสแตติกที่เตรียมไว้ ยังไม่ใช่นโยบายฉบับสมบูรณ์ที่ได้รับอนุมัติ เจ้าของต้องยืนยันผู้ดำเนินการตามกฎหมาย วันที่มีผลใช้บังคับ ประเทศที่ให้บริการ สิทธิด้านความเป็นส่วนตัวที่เกี่ยวข้อง และข้อความภาษาไทยกับภาษาอังกฤษก่อนเปิดให้บริการ ติดต่อสอบถามเรื่องความเป็นส่วนตัวได้ที่ pondd.me@gmail.com การเข้าถึงข้อมูลวิเคราะห์แอป รายงานยอดขายหรือการดาวน์โหลด และข้อมูลวินิจฉัยที่ Apple จัดให้โดยเจ้าของยังไม่ได้รับการยืนยัน รายงานจากแพลตฟอร์มเหล่านี้แยกจากระบบวิเคราะห์ที่ฝังในแอป

ตัวเลือกที่บันทึกไว้ในอุปกรณ์

อุ่นมูนบันทึกรูปลักษณ์และตัวเลือกของตัวละคร ภาษาของนิทาน การตั้งค่าเสียง หน้าที่อ่านค้างไว้ และสถานะการอ่านจบไว้ในอุปกรณ์ ชื่อตัวละครที่เคยตั้งไว้ในรุ่นก่อนอาจยังอยู่ในข้อมูลตัวเลือกด้วย การทำงานของแอปปัจจุบันไม่ได้ส่งข้อมูลเหล่านี้ไปยังเซิร์ฟเวอร์ที่ผู้พัฒนาเป็นผู้ดำเนินการ ส่วนการสำรองข้อมูลของอุปกรณ์เป็นอีกเรื่องหนึ่ง

บัญชีผู้ใช้ การติดตาม และสิทธิ์เข้าถึง

แอปรุ่น Release ที่ตรวจสอบไม่มีบัญชีสำหรับเข้าสู่ระบบอุ่นมูน โฆษณา ระบบวิเคราะห์การใช้งาน การติดตาม หรือการอัปโหลดภาพถ่าย แอปไม่ขอเข้าถึงกล้อง ไมโครโฟน คลังภาพ รายชื่อผู้ติดต่อ หรือตำแหน่งที่ตั้ง ไฟล์ประกาศความเป็นส่วนตัวของแอประบุว่าไม่มีการติดตามหรือการเก็บข้อมูลโดยผู้พัฒนา ข้อค้นพบทางเทคนิคนี้ไม่ทดแทนการอนุมัตินโยบายฉบับสมบูรณ์โดยเจ้าของ

เสียงบรรยายที่บันทึกไว้แล้ว

ไฟล์เสียงบรรยายภาษาไทยและภาษาอังกฤษมาพร้อมกับแอปและเล่นในอุปกรณ์ รวมถึงเล่นแบบออฟไลน์สำหรับนิทานที่คุณมีสิทธิ์อ่าน การอ่านนิทานไม่ส่งข้อความ ชื่อ หรือเสียงไปยังผู้ให้บริการเสียงบรรยาย และไม่สร้างไฟล์เสียงใหม่ การซื้อและการกู้คืนสิทธิ์อ่านอาจยังต้องเชื่อมต่อกับ Apple

การซื้อดำเนินการผ่าน Apple

การซื้อคลังนิทานครั้งเดียวใช้ StoreKit ของ Apple โดย Apple ดูแลบัญชี Apple และขั้นตอนการชำระเงิน อุ่นมูนใช้ข้อมูลการซื้อที่ผ่านการตรวจสอบเพื่อตัดสินว่านิทานเรื่องใดเปิดอ่านได้ การโหลดรายละเอียดสินค้า การซื้อ การกู้คืน และการอัปเดตสิทธิ์อาจมีการติดต่อกับ Apple การกู้คืนการซื้ออาจขอให้ยืนยันบัญชี Apple บริการของ Apple อยู่ภายใต้ข้อกำหนดความเป็นส่วนตัวของ Apple เอง

การลบตัวเลือกในอุปกรณ์

ในเมนูสำหรับผู้ใหญ่ เลือก ลบตัวละครและตัวเลือกในอุปกรณ์ เพื่อลบตัวเลือกของตัวละคร ภาษา การตั้งค่าเสียง และหน้าที่อ่านค้างไว้ในอุปกรณ์นั้น การลบนี้ไม่ลบประวัติการซื้อของ Apple ข้อมูลสำรองของอุปกรณ์ หรืออีเมลที่ส่งถึงฝ่ายช่วยเหลือ การสำรองข้อมูลขึ้นอยู่กับอุปกรณ์และการตั้งค่าของ Apple จึงไม่มีคำรับรองในหน้านี้ว่าจะลบข้อมูลออกจากข้อมูลสำรองด้วย

ตัวเลือกภาษาบนเว็บไซต์

เว็บไซต์แบบสแตติกนี้ใช้ localStorage ของเบราว์เซอร์เพื่อจำภาษาที่คุณเลือกเองระหว่างไทยกับอังกฤษ คุณลบตัวเลือกนี้ได้ในการตั้งค่าข้อมูลเว็บไซต์ของเบราว์เซอร์ เว็บไซต์ไม่มีระบบเข้าสู่ระบบ ระบบหลังบ้าน สคริปต์วิเคราะห์การใช้งาน หรือโฆษณา และโค้ดของเว็บไซต์เองไม่ตั้งคุกกี้ การตรวจสอบภาษาของเบราว์เซอร์ใช้เพื่อแนะนำภาษาในการเข้าชมครั้งแรกเท่านั้น

บริการโฮสต์เว็บไซต์แยกจากแอป

เว็บไซต์นี้เตรียมไว้สำหรับโฮสต์บน GitHub Pages การประมวลผลข้อมูลโดย GitHub แยกจากแอปอุ่นมูนและอยู่ภายใต้นโยบายของ GitHub เอง รายละเอียดบันทึกการเข้าถึง ระยะเวลาเก็บรักษา และสิทธิ์ของเจ้าของในการเข้าถึงข้อมูลโฮสต์ยังไม่ได้รับการยืนยัน แนวทางเก็บตัวเลือกไว้ในอุปกรณ์ของแอปจึงไม่ได้หมายความว่าบริการโฮสต์เว็บไซต์จะไม่ประมวลผลข้อมูลของผู้เข้าชม
