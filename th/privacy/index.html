นโยบายความเป็นส่วนตัว · อุ่นมูน 1.0

ปรับปรุงล่าสุด 11 ตุลาคม 2026 ไม่มีโฆษณา ระบบวิเคราะห์จากผู้ให้บริการภายนอกที่ฝังในแอป หรือการติดตามผู้ใช้ ตัวเลือกการอ่านเก็บไว้ในอุปกรณ์ ส่วนบริการของ Apple อีเมลขอความช่วยเหลือที่เลือกส่ง และการโฮสต์เว็บไซต์อธิบายไว้ด้านล่าง

เกี่ยวกับนโยบายความเป็นส่วนตัวนี้

นโยบายนี้อธิบายแอปอุ่นมูนรุ่น 1.0 และเว็บไซต์นี้ ผู้เผยแพร่อุ่นมูนเป็นบุคคลและจัดการเรื่องความช่วยเหลือกับคำถามด้านความเป็นส่วนตัวด้วยตนเอง ติดต่อได้ที่ pondd.me@gmail.com แอปไม่เก็บรวบรวมหรือส่งข้อมูลส่วนบุคคลหรือข้อมูลการใช้งานไปยังเซิร์ฟเวอร์ของผู้พัฒนา อีเมลขอความช่วยเหลือที่ผู้ใช้เลือกส่ง และบริการของ Apple กับ GitHub อธิบายแยกไว้ด้านล่าง

ตัวเลือกที่บันทึกไว้ในอุปกรณ์

อุ่นมูนบันทึกรูปลักษณ์และตัวเลือกของตัวละคร ภาษาของนิทาน การตั้งค่าเสียง หน้าที่อ่านค้างไว้ และสถานะการอ่านจบไว้ในอุปกรณ์ ชื่อตัวละครที่เคยตั้งไว้ในรุ่นก่อนอาจยังอยู่ในข้อมูลตัวเลือกด้วย การทำงานของแอปปัจจุบันไม่ได้ส่งข้อมูลเหล่านี้ไปยังเซิร์ฟเวอร์ที่ผู้พัฒนาเป็นผู้ดำเนินการ ส่วนการสำรองข้อมูลของอุปกรณ์เป็นอีกเรื่องหนึ่ง

บัญชีผู้ใช้ โฆษณา การวิเคราะห์ และสิทธิ์เข้าถึง

อุ่นมูนไม่มีบัญชีสำหรับเข้าสู่ระบบ ไม่มีโฆษณา ระบบวิเคราะห์การใช้งานจากผู้ให้บริการภายนอกที่ฝังในแอป การติดตามผู้ใช้ หรือฟีเจอร์อัปโหลดภาพถ่าย แอปไม่มีระบบหลังบ้านของผู้พัฒนาสำหรับเก็บข้อมูลผู้ใช้ และไม่ขอเข้าถึงกล้อง ไมโครโฟน คลังภาพ รายชื่อผู้ติดต่อ หรือตำแหน่งที่ตั้ง แอปไม่อัปโหลดตัวระบุอุปกรณ์หรือกิจกรรมการอ่านไปยังผู้พัฒนา

ข้อมูลวิเคราะห์ภาพรวมที่ Apple จัดให้

ผู้พัฒนาใช้รายงานข้อมูลภาพรวมจาก App Analytics ที่ Apple จัดให้ผ่าน App Store Connect รายงานจากแพลตฟอร์ม Apple เหล่านี้แยกจากซอฟต์แวร์วิเคราะห์การใช้งานที่ฝังในแอป อุ่นมูนไม่มี Google Analytics หรือ SDK วิเคราะห์การใช้งานจากผู้ให้บริการภายนอกอื่น ๆ และไม่ส่งตัวเลือกตัวละคร ชื่อ หรือความคืบหน้าการอ่านไปยังผู้พัฒนาเพื่อวิเคราะห์ บริการของ Apple อยู่ภายใต้นโยบายความเป็นส่วนตัวของ Apple เอง

เสียงบรรยายที่จัดเตรียมไว้ล่วงหน้า

ไฟล์เสียงบรรยายภาษาไทยและภาษาอังกฤษจัดเตรียมไว้ล่วงหน้า มาพร้อมกับแอป และเล่นในอุปกรณ์ รวมถึงเล่นแบบออฟไลน์สำหรับนิทานที่คุณมีสิทธิ์อ่าน แอปไม่เรียกบริการสร้างเสียงออนไลน์หรือสร้างเสียงบรรยายใหม่ระหว่างใช้งาน การอ่านนิทานไม่อัปโหลดข้อความ ชื่อ เสียงที่บันทึก หรือข้อมูลผู้ใช้อื่น ๆ ไปยังผู้ให้บริการเสียงบรรยาย การซื้อและการกู้คืนสิทธิ์อ่านอาจยังต้องเชื่อมต่อกับ Apple

การซื้อดำเนินการผ่าน Apple

การซื้อคลังนิทานครั้งเดียวใช้ StoreKit ของ Apple โดย Apple ดูแลบัญชี Apple และขั้นตอนการชำระเงิน อุ่นมูนใช้ข้อมูลการซื้อที่ผ่านการตรวจสอบเพื่อตัดสินว่านิทานเรื่องใดเปิดอ่านได้ การโหลดรายละเอียดสินค้า การซื้อ การกู้คืน และการอัปเดตสิทธิ์อาจมีการติดต่อกับ Apple การกู้คืนการซื้ออาจขอให้ยืนยันบัญชี Apple บริการของ Apple อยู่ภายใต้ข้อกำหนดความเป็นส่วนตัวของ Apple เอง

การลบตัวเลือกในอุปกรณ์

ในเมนูสำหรับผู้ใหญ่ เลือก ลบตัวละครและตัวเลือกในอุปกรณ์ เพื่อลบตัวเลือกของตัวละคร ภาษา การตั้งค่าเสียง และหน้าที่อ่านค้างไว้ในอุปกรณ์นั้น การลบนี้ไม่ลบประวัติการซื้อของ Apple ข้อมูลสำรองของอุปกรณ์ หรืออีเมลที่ส่งถึงฝ่ายช่วยเหลือ การสำรองข้อมูลขึ้นอยู่กับอุปกรณ์และการตั้งค่าของ Apple จึงไม่มีคำรับรองในหน้านี้ว่าจะลบข้อมูลออกจากข้อมูลสำรองด้วย

เมื่อผู้ใหญ่ส่งอีเมลขอความช่วยเหลือ

ผู้ใหญ่สามารถเลือกส่งอีเมลไปที่ pondd.me@gmail.com ผู้เผยแพร่เป็นบุคคลและจัดการอีเมลด้วยตนเอง โดยใช้ที่อยู่อีเมลของผู้ส่ง ข้อความ และไฟล์แนบเพื่อให้ความช่วยเหลือเกี่ยวกับคำขอนั้นเท่านั้น ผู้เผยแพร่ไม่ส่งต่ออีเมลขอความช่วยเหลือให้บุคคลอื่นและไม่ใช้ข้อมูลจากอีเมลเพื่อการตลาด การรับส่งและเก็บอีเมลใช้บริการ Gmail และบริการอีเมลของผู้ส่ง ซึ่งอาจประมวลผลข้อมูลตามนโยบายความเป็นส่วนตัวของผู้ให้บริการ ผู้เผยแพร่จะลบอีเมลขอความช่วยเหลือเมื่อครบหนึ่งปีหลังจากแก้ไขเรื่องนั้นแล้ว โปรดส่งเฉพาะรายละเอียดที่จำเป็น และหลีกเลี่ยงชื่อหรือภาพของเด็ก รหัสผ่าน และข้อมูลการชำระเงิน การส่งอีเมลเป็นทางเลือกและแยกจากการใช้งานแอป คุณสามารถใช้ที่อยู่นี้เพื่อสอบถามเรื่องความเป็นส่วนตัวหรือส่งคำขอเกี่ยวกับอีเมลขอความช่วยเหลือได้เช่นกัน

ตัวเลือกภาษาบนเว็บไซต์

เว็บไซต์แบบสแตติกนี้ใช้ localStorage ของเบราว์เซอร์เพื่อจำภาษาที่คุณเลือกเองระหว่างไทยกับอังกฤษ คุณลบตัวเลือกนี้ได้ในการตั้งค่าข้อมูลเว็บไซต์ของเบราว์เซอร์ เว็บไซต์ไม่มีระบบเข้าสู่ระบบ ระบบหลังบ้าน สคริปต์วิเคราะห์การใช้งาน หรือโฆษณา และโค้ดของเว็บไซต์เองไม่ตั้งคุกกี้ การตรวจสอบภาษาของเบราว์เซอร์ใช้เพื่อแนะนำภาษาในการเข้าชมครั้งแรกเท่านั้น

บริการโฮสต์เว็บไซต์แยกจากแอป

เว็บไซต์นี้โฮสต์บน GitHub Pages เมื่อคุณเข้าชม GitHub อาจประมวลผลข้อมูลคำขอเว็บไซต์ตามปกติ เช่น ที่อยู่ IP เวลาที่ส่งคำขอ และรายละเอียดคำขอ รวมถึงบันทึกการเข้าถึง ภายใต้นโยบายของ GitHub เอง การประมวลผลนี้แยกจากแอปอุ่นมูน ระยะเวลาเก็บบันทึกการเข้าถึงและสถานที่จัดเก็บหรือประมวลผลข้อมูลขึ้นอยู่กับ GitHub ผู้พัฒนายังไม่ได้ยืนยันประเทศหรือภูมิภาคที่ใช้จัดเก็บหรือประมวลผลข้อมูลเหล่านี้ การเก็บตัวเลือกของแอปไว้ในอุปกรณ์จึงไม่ได้หมายความว่าบริการโฮสต์เว็บไซต์จะไม่ประมวลผลข้อมูลของผู้เข้าชม
