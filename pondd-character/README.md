# Pondd About character

Reuses Pondd's original rigged character and two dance clips from Screenshot Studio. The exact GLB is served from https://pond1982.github.io/screenshot-studio/models/pondd.glb. Three.js 0.160.0 is loaded from jsDelivr, as in the original.

No build step. The About section supplies its own speech lines. The component loads near the viewport, pauses offscreen and when the tab is hidden, supports keyboard activation, offers a pause control, and uses static poses for reduced-motion visitors. If the model fails, the original cartoon is used; if WebGL or the CDN is unavailable, a text greeting remains.

The hosting provider, site content and existing links are unchanged.
